Datenschutz

Diese Anwendung speichert die von dir eingegebenen Planungsdaten grundsätzlich lokal im Browser.

Dazu wird der lokale Speicher des Browsers (LocalStorage) verwendet. Die Daten werden nicht durch diese Anwendung an einen eigenen Server übertragen.

Wenn du die Browserdaten löschst oder die Website-Daten entfernst, können die gespeicherten Planungsdaten verloren gehen.

Die Anwendung kann über GitHub Pages bereitgestellt werden. Für die Verarbeitung durch den jeweiligen Hosting-Anbieter gelten dessen eigene Datenschutzinformationen.
